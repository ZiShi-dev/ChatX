# Émojis Apple dans ChatX

Le pack utilise le dossier [Apple de RealityRipple/emoji](https://github.com/RealityRipple/emoji/tree/trunk/apple), à la révision `db08071637157a9def981b59beae9a8d64e70778`.

Les 3 772 images sont embarquées localement : tout le dossier Apple, à l’exception du drapeau d’Israël demandé par l’utilisateur. Les catégories, les familles, les gestes, les variantes de peau et les autres drapeaux sont accessibles dans le sélecteur. Une image manquante conserve son texte Unicode.

Les originaux ont des marges transparentes différentes. L’importeur ajuste leurs limites visibles, conserve leurs proportions et les centre sur une toile transparente de 64 × 64 pixels. Les images sont encodées en WebP ; le pack complet occupe 8,10 Mo. La licence fournie par le dépôt et la notice des modifications sont conservées dans `public/assets/emoji/`.

Un message contenant un seul émoji, sans citation, affiche l’émoji sans bulle, avec une pastille séparée pour l’heure et l’état d’envoi/lecture. Plusieurs émojis utilisent une bulle. Les tailles restent constantes dans chaque contexte : 56 pixels pour un émoji seul, 36 pixels pour un message d’émojis multiples, 28 pixels dans le texte.

Le sélecteur affiche 120 éléments à la fois et permet d’en charger davantage. Il conserve le nombre chargé lors d’un changement de catégorie. Les images sont chargées et décodées à la demande ; l’application ne contacte ni GitHub ni un CDN pour les afficher. Le paramètre de version dans leur URL renouvelle les anciennes images mises en cache.

L’importeur de développement est `scripts/import-apple-emoji.mjs`. Il génère les images, `src/lib/emojiAssets.ts` et `src/lib/appleEmojiCatalog.ts`. Il ne s’exécute pas à l’ouverture de l’application.

Vérification : les tests contrôlent les fichiers de toutes les catégories, le découpage des séquences Unicode, l’exclusion demandée, les références des réponses et le statut vu. `scripts/verify-emoji-message-layout.mjs` contrôle dans le navigateur le fond transparent d’un émoji seul, les tailles et la pastille de l’heure.
