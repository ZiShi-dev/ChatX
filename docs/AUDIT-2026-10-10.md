# Vérification de ChatX — 10 octobre 2026

## Corrections confirmées

- PostgreSQL : la pagination autour d’un message référencé échouait avec « column reference id is ambiguous ». Les colonnes des deux pages sont désormais qualifiées avec l’alias de la table. Le test d’intégration réel passe après correction.
- Notifications : un message arrivant dans la zone visible pouvait rester non lu lorsque le contenu changeait sans événement de défilement. Le changement de disposition déclenche désormais la vérification des messages visibles après 900 ms, avec les mêmes protections contre la lecture en arrière-plan et hors de la conversation.
- Lecteur vidéo : son nettoyage conserve la référence du lecteur concerné au lieu de consulter une référence pouvant déjà désigner un autre lecteur.
- Contrôle statique : suppression de code inutilisé et de blocs qui ne faisaient que relancer la même erreur ; documentation des expressions régulières qui filtrent les caractères de contrôle.
- Les scénarios navigateur utilisent maintenant une identité de chiffrement de test configurée, sans contourner la protection des comptes réels.

Chrome : envoi d’image chiffrée, cache après rechargement, proportions et horaire du message sur mobile et ordinateur ; lecteur image/vidéo, zoom, gestes, rotation, navigation, téléchargement, partage et réponse ; expiration et récupération du tour de groupe malgré une horloge incorrecte ; émojis et notifications entre conversations avec processeur ralenti six fois ; message visible marqué comme lu et bannière supprimée dans le chat concerné.

Le scénario réseau dégradé vérifie une lecture hors ligne, sa conservation après rechargement, une réponse réseau perdue puis une reconnexion. Les nouveaux événements restent non lus ; deux écritures suffisent pour synchroniser la lecture. Les suites serveur vérifient aussi les contrats de transport économes, les autorisations, le chiffrement, les limites HTTP et cinq sessions simultanées.

## Limites et points restants

- Onze avertissements de lint concernent principalement les dépendances de hooks React. La compilation signale aussi des bundles dépassant 500 Ko ; ces avertissements ne bloquent pas les parcours testés et restent à suivre.
- Le fichier Android `google-services.json` est absent. Les notifications push lorsque l’application est fermée nécessitent encore la configuration Firebase et un test de bout en bout sur un appareil réel.
- Vérifications effectuées localement avec comptes synthétiques, Chrome et PostgreSQL Docker. Le VPS, ses secrets, le login Google réel et les différents téléphones physiques n’ont pas été contrôlés. L’APK produit est une version debug.
- Ces tests couvrent les parcours listés ; ils ne prouvent pas l’absence de tout défaut sur toutes les plateformes ou conditions réseau.
